# Thomas Bonnier

Robotics and embedded engineer, based near Lyon. Double degree from ECAM LaSalle and Heriot-Watt University (MSc Robotics, Edinburgh).

Right now I'm on a final-year placement at Innodura TB (until February 2027), working on custom test benches, metrology and machine vision with LabVIEW. After that I'm looking for a first job in robotics or embedded systems.

## Recent work

- **MSc dissertation** – sparse-reward reinforcement learning for an underwater arm (BlueROV2 + Alpha5), in MuJoCo-MJX with JAX and PPO. A generic reward-component library reached 0.981 success, ahead of the hand-tuned dense baseline at 0.964 (15 seeds). Code is in a fork of [fast6DOF](https://github.com/sumeros666/fast6DOF).
- **Unibots UK 2026** – autonomous robot built from scratch in a few weeks: ROS 2 Jazzy and AprilTag on a Raspberry Pi 5, motors and ultrasonics on a Servo2040. 4th overall.
- **Alstom Robotics Battle 2025** – 1st place. Autonomous train fleet on a layout revealed on the day (spacing, junction priority, hazard handling).
- **French Robotics Cup** – vision lead: ROS 2 nodes, YOLO under latency limits, camera calibration, ArUco.
